# 局部感受性系数的 √Re_h 因子核查

算例：Re_h=1000，a_s=0，ω̄=0，n=30，c=1，h_r=1/Re_h，R_l=287.822，N=199（脚本 `check_cavity_receptivity_factor.jl`）。

| 量 | 值 |
|---|---:|
| 离散留数 \|Λ\| = \|yᵀb/Q\|（max\|v\|=1） | 0.004565 |
| 受迫问题直接求解 δ·q → x·Λ 的相对误差（\|δ\|=1e-2, 1e-3, 1e-4） | 1.26e-1, 1.27e-2, 1.27e-3（∝\|δ\|） |
| 复现原代码公式 B_w = ((1/R)ũ'(0)u_w + (1/R)ṽ'(0)v_w)/√Re_h，C_r=\|-iB_w/Q\| | 0.144355（论文 0.1436） |
| 同一公式改用分部积分给出的系数 1/(R Re_h) | 0.004565 |
| 二者之比 | 31.6228 = √Re_h |

结论：受迫问题本身（不依赖任何伴随表示）的模态留数为 0.004565。由 V_zz = -1/(R Re_h) ∂²/∂z² 分部积分得到的边界伴随项系数是 1/(R Re_h)，用它即精确重现该留数；原代码与论文式 (boundary forcing projection) 中的 1/(R√Re_h) 使 |C_r| 增大 √Re_h 倍。该因子在固定 Re_h 下是常数，不改变论文中 |C_r| 的趋势、峰值半径和 N 因子排序；但会影响绝对量级，以及与其他坐标缩放的结果（von Kármán 单盘、Thomas 2024）之间的直接比较。
