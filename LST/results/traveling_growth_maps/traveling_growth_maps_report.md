# 行进波增长率云图与中性曲线（对照 Thomas 2024 图 2）

频率 `omega1 = omega*R = [0.0, -5.0, 4.0, 7.9, 10.0]`（旋转系）；网格 `R=50.0:25.0:800.0`，`m=-14:2:80`（仅 Re α>0，与 Thomas 2024 约定一致），共 7440 点；用时 2567.0 s。

候选窗口 -0.5 ≤ Im α ≤ 0.06。筛选：N=49 全谱发现，N=89/109 局部收敛（相对差 < 1.0e-6），zmax=30.0→40.0 局部检验（< 0.0001），Im α < 0.03 的候选做局部 Briggs–Bers，仅 plus 支、远场能量占比 < 0.1 计入。
