# 二阶六维 Modal 外缘条件验证

参数：`R=285.36`, `alpha=0.38482`, `beta=0.07759`, `omega=-0.07759`, `kappa=-0.185`, `N=109`, `zmax=30.0`, `Ainc=epsilon=1e-3`。本文数值中的 `G_full` 沿用项目现有定义：`G_full=∫_0^{z_i}|u_hf|² dz/(epsilon²|Ainc|²)`，不是其平方根。

## 远场 Modal 子空间
- 有界模态数：3；`rank(C)= 3`；`rank(C*Vg)= 3`。
- `||C V_decay||₂ = 4.940109817706452e-16`，`cond(V_decay) = 3.0367687367477654`。

## 六维受迫系统
- 内部动态残差 `||Y'-AY-F||∞ = 3.793296970866947e-21`；原始四变量方程残差 `4.624080198346215e-25`。
- Modal 外缘残差 `||C Y(zmax)||₂ = 2.753220310261593e-22`。

## 零强迫、叠加与幅值缩放
- 零源零壁面：`||Y||₂ = 0.0`。
- 线性叠加相对误差 `||Y_total-Y_volume-Y_wall||/||Y_total|| = 1.427242147759228e-14`。
- 能量恒等式误差 `E_total-E_volume-E_wall-2Re<V,W> = 5.553580772755923e-28`；`E_total=2.3051375137943155e-13`。
- 粗糙度幅值从 `1e-3` 加倍到 `2e-3` 的状态缩放误差：`0.0`。

## 代表点结果
- `G_D=0.2302883863`（六维 Dirichlet），`G_M=0.2305137514`（六维 Modal），代表点的 Modal 相对差约 `0.0978%`。
- 与旧四变量 Dirichlet 的代表点增益差为 `3.76e-7` 相对量级；六维/四变量剖面相对误差约 `4e-5`，因此增益一致性很好，但剖面尚未达到机器精度，应归因于不同状态重构和外缘压力处理的离散差异。
- 负分支精细扫描见 [second_order_modal_peak_scan.csv](second_order_modal_peak_scan.csv)，在本次网格中两种边界条件的最大值均位于 `kappa=0.185`；Modal 与 Dirichlet 增益差随 `|kappa|` 增大，在 `|kappa|=0.28` 约 `0.35%`。
- `N/zmax` 收敛数据见 [second_order_modal_convergence.csv](second_order_modal_convergence.csv)：在 `zmax=30`，`N=109→169` 的增益变化约 `3.2e-7`；`N=169` 时 `zmax=40→50` 变化约 `1.5e-4`，而 `zmax=20→30` 仍约 `7.0e-3`。因此峰值扫描采用 `zmax=30` 可用于趋势判断，但若要给出高精度绝对增益，建议采用 `zmax≥40` 并报告外缘收敛。

## 解释
Modal 条件允许外缘存在有界远场散射状态，因此它与有限外缘三速度 Dirichlet 条件的差异是物理边界模型的差异。代表峰值附近差异小于千分之一，但整个扫描区间已达到约 `0.35%`；在增大外缘高度、改变频率或接近远场模态退化时不能预先假定仍然很小。
